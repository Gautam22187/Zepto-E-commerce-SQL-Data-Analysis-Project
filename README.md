# Zepto E-commerce SQL Data Analysis Project

## Overview

This project analyzes Zepto e-commerce customer shopping data using MySQL. It includes data cleaning, exploratory data analysis (EDA), customer behavior analysis, revenue insights, and category-wise trends using SQL queries.

## Technologies Used

* MySQL
* SQL

## Key Analysis

* Customer purchase behavior
* Revenue analysis
* Category-wise insights
* Gender-wise spending
* Purchase frequency analysis
* Customer segmentation

## SQL Concepts Used

* SELECT
* GROUP BY
* ORDER BY
* HAVING
* CASE Statements
* Aggregate Functions
* UPDATE & DELETE
